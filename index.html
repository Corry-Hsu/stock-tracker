JSON 欄位設計規範 (Schema)

1. 如何切換「追蹤中」與「已出場固定」？

每個標的物件只需設定以下兩個欄位即可控制：

  • "status": "active" | "exited"
  • "trackLive": true | false

當 status: "exited" 或 trackLive: false 時，系統會固定使用 exitPrice 計算最終損益，不再隨即時報價跳動。
